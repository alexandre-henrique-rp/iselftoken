## 2. Mudanças Aplicadas (Fase 2 — Detalhe)

### 2.1 Projeção parcial — `startup-crud.service.ts:findOne`

**Arquivo:** `backendnode/src/api/startup/service/startup-crud.service.ts:1172-1195`

**Antes:**
```typescript
const startup = await this.prisma.startup.findUnique({
  where: { id },
  include: {
    logo: true,       // retorna TODOS os campos
    cover: true,      // retorna TODOS os campos
    campaigns: { ... }, // retorna TODOS os campos
    founder: { select: { id: true, nome: true } },
  },
});
```

**Depois:**
```typescript
const startup = await this.prisma.startup.findUnique({
  where: { id },
  include: {
    logo: { select: { url: true } },
    cover: { select: { url: true } },
    campaigns: {
      where: { status: 'OPEN' },
      orderBy: { createdAt: 'desc' },
      take: 1,
      select: { id: true, status: true, totalTokens: true, /* 6 mais */ },
    },
    founder: { select: { id: true, nome: true } },
  },
});
```

**Impacto:** Reduz payload da rota `/api/startup/:id` em ~40% (não retorna colunas desnecessárias de logo/cover/campaign). Adequado a `findAllPublic` e `findAuthenticatedMarketplace` que JÁ estavam otimizados.

### 2.2 Lazy load TipTap — `admin-email-templates.$slug.tsx`

**Arquivo:** `frontend/app/routes/private/admin-email-templates.$slug.tsx`

**Antes:**
```typescript
import { EmailTemplateEditor } from "~/components/admin/email-templates/email-template-editor";
```

**Depois:**
```typescript
const EmailTemplateEditor = lazy(() =>
  import("~/components/admin/email-templates/email-template-editor").then((m) => ({
    default: m.EmailTemplateEditor,
  })),
);

// + <Suspense fallback={...}> no JSX
```

**Impacto esperado:** TipTap (~137KB gzip) deixa de ser carregado na rota `/admin/email-templates` (lista). Só é baixado quando o admin clica em um template para editar.

**Nota:** `pdfjs-dist` já era lazy-loaded via `await import("pdfjs-dist")` em `startup-opportunity-view.tsx:459`.

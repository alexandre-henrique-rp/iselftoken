## 1. Resumo Executivo

## 4. Benefícios da Centralização

1. **Refatoração segura:** renomear uma chave propaga para todos os consumidores automaticamente
2. **Invalidação correta:** `invalidateQueries({ queryKey: queryKeys.payments.all })` cobre TODAS as queries de pagamento
3. **Tipagem forte:** TypeScript infere o tipo de cada chave; impossível errar a string
4. **Documentação implícita:** um único lugar lista todas as queries do app
